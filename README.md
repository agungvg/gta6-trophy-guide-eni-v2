Sunset Ledger — a GTA VI Trophy Guide & Tracker. A static, offline web app covering all 55 GTA VI trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze) with local progress tracking (export/import JSON), filters, search, a 3-stage roadmap, a missables guide, and sourced references with unconfirmed points flagged honestly.

## Run it

```sh
open app/index.html
```

Or serve the folder with any static server, for example `python3 -m http.server` and open http://localhost:8000/app/.
